# HakiSend Publisher 0.1.43

This release republishes the completed 0.1.42 Community review candidate with its required GitHub Release assets attached before publication.

## What's included

- Publish website posts and email content from your local Markdown notes to HakiSend.
- View the native read-only website and email content calendar.
- Validate custom HakiSend API origins as HTTPS-only and require secure browser-based authorization.
- Preserve the source and build changes validated in the completed 0.1.42 Community branch preview.

## Release integrity

- The `main.js` runtime and `styles.css` bytes are identical to 0.1.42; only version metadata changes.
- The package includes `main.js`, `manifest.json` and `styles.css` as separate release attachments.
- Mobile behavior has not been verified in this release cycle.
